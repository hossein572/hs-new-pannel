# HS Panel

یک سیستم مدیریت پروکسی چند پروتکله با پشتیبانی از:

- **VLESS** (WebSocket, XHTTP)
- **Trojan** (WebSocket, XHTTP)
- **MTProto** (تلگرام)
- **Shadowsocks**

## ویژگی‌ها

- 🎛️ داشبورد وب ریسپانسیو
- 🔐 ورود با **نام کاربری + رمز عبور** (بدون ایمیل، بدون کد تأیید، بدون SMTP)
- 👥 چند‌کاربره: پنل هر اکانت از بقیه **جدا** است (کانفیگ‌ها، گروه‌ها، ترافیک و لاگ فعالیت‌ها)
- 🛡️ نقش‌ها: «ادمین» به همه‌ی پنل‌ها + تنظیمات ورکر/Railway/نودها دسترسی دارد، «کاربر» فقط دیتای خودش را می‌بیند
- 📊 مانیتورینگ ترافیک و اتصالات
- 🌐 ساخت خودکار لینک‌های اشتراک
- 📦 بکاپ و ریستور
- 🔄 آپدیت خودکار

## نصب

```bash
pip install -r requirements.txt
python main.py
```

## ورود پیش‌فرض

در اولین اجرا یک اکانت ادمین ساخته می‌شود و در `data/hs_state.json` ذخیره می‌گردد:

| مورد | مقدار پیش‌فرض | متغیر محیطی |
| ---- | -------------- | ------------- |
| نام کاربری | `hossein` | `ADMIN_USERNAME` |
| رمز عبور | `hossein2022` | `ADMIN_PASSWORD` |
| پورت | `8000` | `PORT` |
| ثبت‌نام خودکار کاربران | روشن | `ALLOW_SIGNUP=0/1` |

> رمز عبور ادمین پس از اولین اجرا دیگر از env خوانده نمی‌شود؛ برای بازنشانی،
> از بخش «کاربران» پنل ادمین استفاده کنید یا `data/hs_state.json` را پاک کنید.

## ورود / ثبت‌نام در پنل

- صفحه‌ی `/login` فقط دو فیلد دارد: **نام کاربری** و **رمز عبور**.
- با تب «ساخت اکانت» هر کسی می‌تواند برای خودش اکانت مستقل بسازد (اگر `ALLOW_SIGNUP` روشن باشد).
- نام کاربری: `a-z`, `0-9`, `.`, `_` با طول ۳ تا ۳۲ (حساس به بزرگی/کوچکی حروف نیست).
- رمزها با **PBKDF2-HMAC-SHA256 + salt اختصاصی** هش می‌شوند و هیچ‌گاه به‌صورت خام ذخیره یا ارسال نمی‌شوند.
- پس از ۶ تلاش ناموفق برای یک نام کاربری، ورود ۵ دقیقه قفل می‌شود.
- ادمین از بخش «کاربران» می‌تواند اکانت بسازد، رمز را بازنشانی کند، کاربر را مسدود کند یا با یک کلیک همه‌ی دیتای او را هم پاک کند.
