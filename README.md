# HS Panel

یک سیستم مدیریت پروکسی چند پروتکله با پشتیبانی از:

- **VLESS** (WebSocket, XHTTP)
- **Trojan** (WebSocket, XHTTP)
- **MTProto** (تلگرام)
- **Shadowsocks**

## ویژگی‌ها

- 🎛️ داشبورد وب ریسپانسیو
- 🔐 احراز هویت با **نام کاربری و رمز عبور** (بدون ایمیل)
- 👥 **چندکاربره**: هر کاربر پنل کاملاً مستقل خودش را دارد (کانفیگ‌ها، گروه‌ها، نودها و آمار جدا)
- 📊 مانیتورینگ ترافیک و اتصالات
- 🌐 ساخت خودکار لینک‌های اشتراک
- 📦 بکاپ و ریستور (به‌تفکیک هر کاربر)
- 🔄 آپدیت خودکار
- 🔤 فونت **Iran Sans** در کل پنل

## نصب

```bash
pip install -r requirements.txt
python main.py
```

## ورود

- ورود **اجباری** است — بدون لاگین هیچ بخشی از پنل قابل دسترسی نیست.
- **ثبت‌نام**: از صفحه لاگین، تب «ثبت‌نام» — نام کاربری + رمز عبور.
  حساب در سیستم ثبت می‌شود و پنل مستقل مخصوص همان حساب ساخته می‌شود.
- **ورود**: نام کاربری + رمز عبور.

### حساب مالک (پنل اصلی متصل به Cloudflare Worker)

- نام کاربری: `hossein`
- رمز عبور: `hossein2022`
- این حساب موقع استارتاپ به‌صورت خودکار ساخته می‌شود (آدمین) و تمام داده‌های

## ذخیره‌سازی

داده‌ها در `DATA_DIR` (پیش‌فرض `/data`، در غیر این صورت `./data`):

- `hs_state.json` — فرمت v2:
  ```json
  {
    "version": 2,
    "users": { "hossein": { "password_hash": "...", "is_admin": true } },
    "data": {
      "hossein": { "links": {}, "subs": {}, "nodes": {}, "node_keys": {} }
    }
  }
  ```
- فرمت‌های قدیمی (تک‌کاربره/ایمیلی) موقع استارتاپ به‌صورت خودکار مهاجرت می‌شوند.

## تنظیمات سرور (اختیاری)

```bash
PORT=8000           # پورت (پیش‌فرض 8000)
DATA_DIR=./data     # محل ذخیره state
PUBLIC_HOST=...     # دامنه (برای ساخت لینک‌های اشتراک)
SECRET_KEY=...      # کلید هش رمزهای عبور (پیش‌فرض: ساخت خودکار و ذخیره در DATA_DIR)
ADMIN_USERNAME=hossein
ADMIN_PASSWORD=hossein2022
RELOAD=1            # ری‌لود خودکار در توسعه محلی
```
